# caisse_enregistreuse

Ce script simule une caisse enregistreuse en C qui :

- Génère aléatoirement un montant à payer.

- Demande à l'utilisateur un montant donné.

- Calcule et rend la monnaie en priorisant les plus gros billets/pièces.

- Gère un stock limité de monnaie.

- Permet de remplir ou fermer la caisse si le stock est insuffisant.

## Compilation

gcc script/caisse.c -o caisse
